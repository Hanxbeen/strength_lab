# 문헌 검토·근거 데이터 명세

문서 ID: EVD · 버전 0.2 · 2026-10-12 KST
상태: 내부 재검토를 반영한 설계안. 문헌 검토 수행 결과 또는 과학적 승인서가 아니다.  
연결 원칙: P01, P02, P03, P05, P06, P09, P10

## 1. 목적과 산출물

파워리프팅 중량 향상에 필요한 판단을 질문으로 정의하고, 질문별 근거·적용 조건·불확실성·공백을 데이터화한다. 논문 수나 파싱 성공을 추천 기준으로 사용하지 않는다.

산출물은 질문 목록, 검색 기록, 포함·제외 목록, 연구·실험군 추출표, 질문별 근거 종합, 판단 규칙 후보와 검토 이력이다. 초기 방식은 범위를 정한 근거 지도와 질문별 심층 검토다. 실제 절차를 갖추기 전 ‘체계적 문헌고찰 완료’, ‘PRISMA 인증’, ‘과학적 자동 검증’이라고 표현하지 않는다.

## 2. 코칭 질문 목록

질문마다 대상(P), 개입(I), 비교(C), 결과(O), 평가 기간(T), 실제 사용 시점을 명시한다. 아래 목록은 검색 범위이며 답이 이미 존재한다는 뜻이 아니다.

| ID | 판단 영역 | 확인할 질문과 결과 | 적용 시점 |
|---|---|---|---|
| Q01 | 시작 기준 | 동작별 측정 1RM·추정 1RM·RM 기록을 어떤 조건에서 사용할 수 있는가? | 등록·시작 |
| Q02 | 기본 구성 | 강도·반복수·세트·빈도·진행 방식의 조합은 SBD 기록에 어떤 결과를 보이는가? | 선택·주차 편성 |
| Q03 | 수행 조절 | 목표 미달·초과 수행 시 부하·볼륨 조절의 조건과 효과는 무엇인가? | 세트·세션 후 |
| Q04 | 휴식 | 세트·동작·운동일 사이 휴식 조건과 결과는 무엇인가? | 수행·일정 |
| Q05 | 보조 훈련 | 특정 보조 운동이 목표 동작 기록에 직접 영향을 보였는가, 간접 근거인가? | 프로그램 구성 |
| Q06 | 근비대 | 근비대 목적의 작업을 SBD 훈련과 병행할 근거·부담은 무엇인가? | 프로그램 구성 |
| Q07 | 회복·피로 | 수면·주관적 회복·수행 저하 정보를 훈련 결정에 사용할 근거는 무엇인가? | 운동 전·추세 검토 |
| Q08 | 정체·장기 진행 | 정체 정의·평가 기간·조정·휴식 주기와 관련한 근거는 무엇인가? | 블록 종료·문제 발생 |
| Q09 | 피킹·평가 | 기록 측정·대회 전 훈련 변경과 평가 표준화의 근거는 무엇인가? | 평가 전후 |
| Q10 | 현실 제약 | 제한된 시간·장비·빈도·결석에 대한 대안이 어떤 조건에서 연구됐는가? | 선택·일정 변경 |
| Q11 | 이력 활용 | 과거 수행으로 다음 부하를 정할 방법·오차·적용 한계는 무엇인가? | 다음 세션·다음 프로그램 |
| Q12 | 지속·부담 | 수행률·중도 이탈·부작용·입력 부담이 효과 해석과 제공 범위에 어떤 영향을 주는가? | 전 과정 |

필요에 따라 하위 질문을 추가하되 질문 버전과 변경 이유를 남긴다. 일반 건강·체중 감량·진단·재활 처방은 초기 자동 코칭 범위에 포함하지 않는다. 근거 지도에서 맥락 자료로 다룰 수는 있다.

## 3. 검색·선별 절차

EVD-01. 검색 시작 전에 질문, 대상 범위, 결과 지표, 기간·언어 제한과 이유, 데이터베이스, 검색식, 재검색 기준을 기록한다. 날짜 제한을 두지 않는 검색도 그 사실을 적는다.

EVD-02. PubMed 등 접근 가능한 학술 검색원, 관련 종설의 참고문헌, 인용 추적을 함께 사용한다. SPORTDiscus·Scopus 등 접근하지 못한 자료원은 미검색으로 기록한다. 검색엔진 결과 일부만으로 모든 관련 연구를 확인했다고 주장하지 않는다.

EVD-03. 검색일·검색식·필터·검색원·조회 건수·수집 건수·실패 범위·커서/페이지를 SearchRun에 저장한다. 원문 접근 실패와 학술적 제외를 분리한다. 유료 원문은 미확보 상태로 남기며 공개 원문만으로 편의 표본이 구성됐는지 표시한다.

EVD-04. 제목·초록 선별 → 원문·보충자료 검토 → 자료 추출 → 질문별 종합 순서로 진행한다. AI는 후보를 정리하지만 최종 포함·제외와 실행 관련 추출값은 검토자가 확인한다. 번역·OCR 사용 및 검증 상태를 기록한다.

EVD-05. 연구 유형별 용도를 분리한다. 대조 실험은 비교 효과, 관찰 연구는 연관·실행 맥락, 질적 연구·전문가 의견은 경험·공백 파악에 사용한다. 종설을 포함하면서 그 안의 동일 연구를 독립 표본으로 중복 집계하지 않는다. 프리프린트는 출판 상태를 구분하고 단독으로 자동 처방을 승인하지 않는다.

EVD-06. 무효·불리·상충 결과와 탈락을 보존한다. p값, 유명 저널, 인용 수, 발행 연도, 효과 크기 한 항목만으로 채택하지 않는다. 전후 향상만 있는 결과를 비교군 대비 우월성으로 바꾸지 않는다.

## 4. 데이터 사전

ID는 내부 안정 ID이고 DOI·PMID는 외부 식별자다. 모든 변경 가능한 정의는 버전을 가진다. 확인되지 않은 데이터는 값 null과 사유를 함께 저장한다.

| 개체 | 필수 내용 |
|---|---|
| CoachingQuestion | question_id/version, PICTO, 사용 시점, 적용 범위, coverage_status |
| SearchRun | 검색 조건·시각·출처·건수·완료/실패·제한·후속 추적 |
| Report | report_id, DOI/PMID 등, 제목·저자·연도, 출판 상태, 정정/철회 연결 |
| SourceSnapshot | source_snapshot_id, report_id, 조회 시각, URL, 콘텐츠 해시, 원문/보충자료 구분, 접근·이용 권한 |
| Study | study_id, 등록정보, 설계, 장소, 모집·선정 조건, 자금·이해상충, report_ids |
| Cohort | cohort_id, 표본수·배정·분석수·탈락·훈련 경력·대상자 특성, 중복 가능성과 판정 근거 |
| Arm | arm_id, cohort_id, 실험/비교군 역할, 공통 훈련과 군별 개입, 전체 일정·운동·강도·휴식·변경 규칙 |
| Outcome | outcome_id, 동작·가동범위·장비·측정/추정 구분, 측정 시점, 군별 통계·단위, 비교 효과·구간, 분석대상수 |
| Extraction | 필드 경로·값·단위·missing_reason, snapshot_id, 절/표/행/열/페이지, 추출 방식, 검토자·시각 |
| EvidenceClaim | claim_id/version, question_id, 관련 비교·결과·독립 코호트, 적용 조건, 불확실성, 상충·반대 근거, 검토 상태 |
| DecisionRule | rule_id/version, claim_refs, 입력 조건·분기·출력·범위·제외·중단·fallback, 출처 유형, 검토 기록 |
| ProgrammeDefinition | programme_id/version, 목적·대상·전체 구성·종료·평가, arm_refs/rule_refs, 검토 기록 |

missing_reason은 not_reported(미보고), inaccessible(미확보), unclear(모호), not_applicable(해당 없음), not_yet_reviewed(미검토)를 구분한다. 0·없음·정상으로 치환하지 않는다. 동일 논문의 여러 실험과 동일 참여자의 여러 결과를 독립 연구 수로 세지 않는다.

Outcome에는 SD, SE, CI 등 통계 종류를 명시한다. 환산은 원값·공식·가정을 보존하고 검토하며, 변화량 분산을 근거 없이 만들지 않는다. 반복측정·교차설계·공유 비교군 등 의존성을 표시한다. 원자료가 없는 경우 개인 성장 분포를 복원하지 않는다.

## 5. 근거 판단과 추천 가능성의 분리

PRISMA는 보고 지침으로 참고한다. 근거 확실성은 개별 논문의 합격 점수가 아니라 특정 비교·결과에 대한 근거 묶음에서 검토한다. 편향 위험, 일관성, 간접성, 정밀도, 출판 편향을 각각 기록한다. 이 구조는 Cochrane의 GRADE 설명을 참고하되, 정식 절차와 역량을 갖추지 않았다면 GRADE 평가 완료로 표시하지 않는다.

EVD-07. 초기 certainty_assessment는 unassessed 또는 structured_narrative이며 평가자·방법·판단 이유를 필수로 둔다. 임의 가중합 점수로 ‘신뢰도 93%’를 만들지 않는다. 연구 유형에 맞는 평가 도구·버전과 평가자 역량은 질문별 검토 계획에 지정한다.

EVD-08. 질문별 coverage_status는 unsearched / in_review / supported_with_limits / conflicting / insufficient이다. 이는 무게무게의 작업 상태이지 학술적 등급이 아니다. 모든 질문에 유효 처방을 강제로 만들 필요는 없으나, 출시 기능이 의존하는 공백에는 동작 가능한 fallback이 있어야 한다.

EVD-09. 대상자 성별·연령 등이 원 연구와 다르다는 이유만으로 모든 사용을 일괄 금지하지 않는다. 직접성의 차이를 평가하고, 배포되는 각 규칙에 applicability 조건과 fallback을 명시한다. 반대로 사용자가 동의했다는 이유만으로 적용 근거가 확보된 것으로 처리하지 않는다.

## 6. 원문에서 제품으로 넘어가는 검토

추출 검토 → 근거 해석 검토 → 프로그램 전체 검토 → 구현·표현 검증을 별도 기록한다. 해시 일치나 테스트 통과는 앞 단계 검토를 대체하지 않는다.

EVD-10. 실제 자동 처방에 쓰는 수치·동작·비교군·진행 규칙은 최초 추출과 분리된 원문 대조 확인을 거친다. 과학적 해석에는 운동과학/근력 코칭과 문헌 해석 역량을 갖춘 검토자를 지정하고 검토 범위·이해상충을 기록한다. 자동 처방의 핵심 해석을 구현 담당자 단독으로 승인하지 않는 것을 출시 기준으로 제안한다. 담당자가 확보되지 않으면 candidate 상태로 보존하고, 해당 자동 처방은 활성화하지 않는다. 이 기준은 향후 운영 정책이며 현재 외부 검토가 있었다는 뜻이 아니다.

EVD-11. 내부 권고 준비 단계는 candidate / reviewed / release_eligible / rejected / suspended이다. release_eligible은 과학적으로 입증됐다는 배지가 아니라 필요한 검토·입력·fallback이 준비됐다는 제품 상태다. 실제 제공 여부는 업데이트 명세의 Release가 결정한다.

원문 재현에 필수적인 정보가 없으면 사용자에게 난해한 빈칸을 모두 넘겨 ‘준비 완료’로 만들지 않는다. 검토된 제품 정책으로 채우되 출처를 구분하거나 실행 제공을 보류한다. 근거 상세 정보 열람은 실행과 별개로 제공할 수 있다.

제품 정책이 실제 훈련 부하·빈도·휴식·적용 대상을 바꾸면 EVD-10의 검토 범위에 포함한다. 숫자를 product_policy로 표시하는 것만으로 근거 공백이나 검토를 우회할 수 없다. 카피·색상 등 처방과 무관한 운영 선택까지 학술 검토를 요구하는 것은 아니다.

## 7. 수집 종료·공백 관리

초기 라운드 종료 조건: 지정 검색원을 실행했고, 중복·선별·미확보 이유가 기록됐고, 모든 Q01~Q12에 coverage_status와 다음 행동이 있으며, 출시 대상 규칙의 근거·모순·fallback 검토가 끝난 상태. 아직 근거가 부족한 질문은 insufficient로 닫을 수 있다. ‘세상 모든 논문 수집 완료’는 종료 조건이 아니다.

새로운 하위 질문이 생기면 검색 범위를 버전으로 확장한다. 기간·운영 자원 때문에 중단한 검토는 완료가 아니라 paused로 별도 관리한다.

## 8. 인수 조건과 현재 상태

- 출처 없는 실행 수치, 비교군 오연결, 코호트 이중 집계, 미보고 값의 자동 생성은 release_eligible을 차단한다.
- 실패·불일치 사례도 포함한 원문 대조 참조 집합으로 추출을 평가한다. 추출기에 사용한 동일 규칙이 스스로 정답을 만드는 테스트만으로 완료하지 않는다.
- 근거가 부족한 질문에 ‘부족함’과 사용자가 할 수 있는 다음 행동을 반환할 수 있어야 한다.
- 원문·이미지·표·보충자료의 이용 범위를 개별 확인한다. 공개 접근 가능성을 서비스 재배포 권한으로 간주하지 않는다.

현재 3편·5개 source template은 추출·실행 시제품이다. 이 명세의 질문별 검색·종합·검토를 완료한 코칭 데이터셋이 아니다. 실제 문헌 검토, 권리 확인, 검토자 지정은 아직 수행해야 한다.
