# 전체 명세 적대적 재검토 기록

문서 ID: AUDIT · 버전 0.1 · 2026-10-12 KST

## 1. 검토 범위와 판정

서비스 원칙과 네 후속 명세를 과학적 타당성, 사용자 가치, 개인화 논리, 데이터 의미, UX, 운영, 개인정보, 구현 전환 관점에서 검토했다. 검토 방식은 동일 작성자의 별도 반례 점검과 문서 교차 대조다. 독립 전문가 심사·실제 사용자 연구·새로운 전체 문헌 검토를 수행한 것은 아니다.

판정: 문서 묶음은 구현 논의와 문헌 검토 착수에 사용할 수 있는 설계안으로 정리됐다. 실제 코칭의 효과·서비스 출시 적합성을 승인한 것은 아니다. 미확정 처방값은 제한된 기능 범위와 fallback을 연결해 남겼다. 더 많은 논문이나 테스트 수로 이 공백을 가리지 않는다.

검토 완료란 아래 반례에 대한 명세상 기대 동작을 정했다는 의미다. 구현이 그 동작을 충족하는지는 별도 인수 검증 대상이다.

위 점검은 모든 가능한 반례를 포괄하지 않는다. 신규 원문 형식·대상·훈련 구조가 생기면 질문과 검증 시나리오를 추가한다.

## 6. 문서 품질 확인

구조 점검은 파일 간 링크, 원칙/질문/문서 ID, 예시 계산, 목표/실제 구분, 결측·0 분모·버전·공개 상태를 대상으로 한다. 결과는 묶음의 DOCUMENT_CHECK.json에 기록한다. 이 파일은 문서 검사 결과이며 코드 테스트·임상/운동 효과 검증 결과가 아니다.

본문과 계산을 수정한 뒤 동일 기준으로 다시 확인한다. 최종 문서는 원칙 0.2와 네 명세 0.2이며, 본 재검토 기록 및 README와 함께 저장소 반영 대상으로 묶는다.
