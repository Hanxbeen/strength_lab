## 적대적 검토와 제품 변경
1. 본문 SBD와 보충표 front squat 표기는 충돌한다. 오타라고 단정하거나 백스쿼트로 대체하지 않는다.
   사용자는 선택 화면과 시작 입력에서 이 차이를 확인한다. 동의가 연구 검증을 대신하지 않는다.
2. 연구 참여자는 남성, 저항훈련 2년 이상·PL 1년 이상, 이전 70–90% 부하 경험자였다.
   분류 experienced는 제품 탐색 분류이며 논문의 경쟁 등급 beginner/intermediate를 입문자로 번역하지 않는다.
3. 원 연구는 감독 및 사전 RPE 연습 4주를 포함했다. 앱은 감독을 재현하지 않는다.
   제품에서 성인, 독립 SBD 및 front squat 수행, RPE 활용 경험과 이전 부하 경험을 요구한다.
   자기보고 조건 통과를 자세·건강·적합성 검증으로 표시하지 않는다.
4. 원 연구는 비무작위 소규모 pilot이며 PER 분석 3명이다. 집단 효과를 개인 성장 목표로 변환하지 않는다.
   부상 중도탈락도 원자료 한계로 유지한다.
5. 중량은 고정한 측정 SBD 1RM과 검증된 표의 기준을 사용한다.
   원표 2.5 kg 반올림을 사용자의 장비 간격으로 바꾸는 것은 제품 규칙이다.
6. 휴식·추가 준비운동은 사용자 선택, 회차 간 48시간은 제품 일정 규칙이다.
   연구가 증명한 최적 휴식이나 회복 임계값으로 표시하지 않는다.
7. 연구 RPE 9 상한 안내를 실행 데이터에도 전달한다. 통증/피로 사유만으로 감량 계수를 만들지 않는다.
   사용자 감량·반복 변경·휴식 단축/연장·중단은 원래 계획과 분리 기록한다.
8. 프런트스쿼트 별도 1RM을 요구하지 않는다. 평가에서는 별도 종목으로 표시하되 SBD 합계에 넣지 않는다.

## 공개 조건과 호환성
backend/programme_access.py의 정확한 해시만 일반 로그인 사용자의 명시적 선택에 허용한다.
scientific_approval=false, independent_expert_review=false를 유지한다.
새 카탈로그 RPC v5만 새 어댑터를 포함한다. v3/v4 함수 및 기존 응답 집합은 변경하지 않는다.
기존 PER 조정안은 내부 상태로 유지하며 새 정의가 과거 인스턴스/결과를 덮어쓰지 않는다.
DB 반영과 검증 결과의 최신 상태는 docs/CURRENT.md를 따른다.
