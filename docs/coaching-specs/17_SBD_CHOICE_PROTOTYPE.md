# SBD 직접 선택 조정안 — 내부 실행 계약

2026-10-16. 16 문서의 후속 결정 및 구현. 공개 초급 처방 승인 아님.

## 결정과 범위

Petrizzo 원문 Procedures pp.86–87을 다시 확인했다. 5RM 평가뿐 아니라 모든 훈련도 실시간 감독하에 진행했다.
감독 없는 초급 자동 처방의 근거는 확보하지 못했다. 감독하 평가를 임의 %1RM 또는 RPE로 대체하지 않는다.
이번에는 일반 사용자 처방을 확대하지 않고, 이미 SBD를 독립 수행하는 성인의 **내부 기록·선택 시제품**으로 좁혔다.
사용자 동의 또는 internal allowlist는 과학적 승인이나 안전성 검토를 대신하지 않는다.

주간 날짜 간격은 기존 programme-schedule-v1 제품 정책이다. 원문 안전 임계값이 아니다.

## 기존 API에 연결

- 정의: data/research/coaching/novice-sbd-choice.json. 실행기: novice-sbd-choice-v1.
- 인스턴스 arm=SBD_2D_OMISSION, setup.adaptation_id=petrizzo_ohp_omitted_2d_v1 필수.
- 기존 programme-readiness는 입력 충족과 추천 적합성을 분리하고 not_assessed를 유지한다.
- 기존 next-session 응답에 session_inputs를 추가한다. **운동 시작 전에** 종목별 최근 원 목표/실제/사유/휴식과 요구 입력을 확인할 수 있다.
- 시작 요청은 initial_loads_kg를 사용한다. 기존 initial_rpe_loads_kg는 그대로 유지하고 교차 사용은 거부한다.
- 12주차를 지원하도록 요청 상한을 확장하되 각 기존 실행기의 기간/요일 검증은 유지한다.
- 중복 시작은 같은 중량일 때만 기존 결과 반환. 변경된 중량을 같은 요청으로 재사용하면 충돌이다.
- 다음 기록의 참고는 같은 요일이 아니라 같은 종목의 가장 최근 수행이다. 이벤트 해시를 함께 고정한다.
- 원 목표 완료/변경 또는 미완수/이전 세션 미완료/통증 맥락/이력 없음 구분. 평균 중량 하나로 합치지 않는다.
- 선택값은 user_choice, automatic_load_kg=null. 기록을 보여준 것만으로 자동 개인화 완성이라고 부르지 않는다.
- 추정 시작 1RM과 실측 종료 1RM의 차이를 성장률로 계산하지 않도록 종료 평가를 보완했다.

## 적대적 재검토와 남은 제한

1. 원문과 다른 조합이다. 따라서 원문 재현 또는 검증된 초급 루틴으로 공개하지 않는다.
2. 기존 API의 필수 1RM 조건을 이 시제품에서는 제거했다. 미등록/일부 등록도 가능하다.
   추정값은 중량 계산에 쓰지 않고, 기준이 없거나 추정값이면 실측 성장률을 계산하지 않는다.
3. 매 회차 직접 중량 선택이 필요하다. 자동 코칭의 공백은 남아 있으며 기록 화면만으로 차별성이 입증되지 않는다.
4. 준비운동은 안내 문자열이며 본세트 원장에 실제 수행이 포함되지 않는다. 전체 운동 재현 완료라고 표현하지 않는다.
5. 긴 결석 이후 일정상 시작 가능해도 부하 적합성을 판단한 것이 아니다. 통증 기록에 감량 수치를 제시하지 않는다.

공개 차단은 기존 서버 소유 allowlist와 카탈로그 재확인으로 유지한다.
원문 검토 JSON을 실행 정의로 바꾸지 않았다. 기존 원문 사실은 그대로 남는다.
DB 적재·서버 배포·iOS 연결은 이번 구현의 완료 항목이 아니다.
현재 DB의 coaching_programme_catalog_v2는 이전 실행기 3종만 반환한다. 여기에 새 실행기를 무조건 노출하면
이전 서버의 전체 카탈로그 검증이 실패할 수 있다. 다음 배포는 구버전 조회를 보존한 새 카탈로그 계약과
서버 지원을 함께 검증한 뒤 내부 자료를 적재해야 한다. 코드 테스트의 카탈로그 대역을 실제 DB 조회로 보고하지 않는다.

## 검증 기준

최초 1RM 변경에 따른 처방 불변, 최근 종목 참고, 감량/결측/통증 구분, 추정 기준 성장률 차단을 테스트한다.
