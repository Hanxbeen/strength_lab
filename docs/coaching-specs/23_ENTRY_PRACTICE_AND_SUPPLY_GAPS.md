# 입문 연습 실행과 실제 공급 공백
2026-10-18. 전체 숙련도 공급 완료 문서가 아니라 구현 범위와 차단 항목 기록이다.

## 이번 구현
- /v3/entry/pathway: SBD에 연결되는 세 움직임 학습 카드.
- /v3/entry/practices: 시작/목록/상세/이벤트/무활동 중단.
- 지도자 동반, 장비 확인, 성인, 현재 통증 없음 조건. 자기보고는 객관적 기술 평가가 아니다.
- 회수 미기록은 null. 임의 세트·반복·kg·휴식 처방 없음. 사용자가 실제 연습/휴식 기록.
- 통증·도움 요청 시 stopped. 한 시간 무활동 중 열린 휴식은 실제 휴식으로 확정하지 않음.
- 완료 후 바벨 훈련 자동 해제 없음. 1RM 자동 생성 없음.
- 기존 execution_workouts 원장/소유자 RLS/트랜잭션을 재사용. 새 테이블/마이그레이션 없음.
- 교육 정의는 서버 코드 버전이며 DB 카탈로그에 추가된 훈련 루틴이 아니다.
- 로컬 SQLite 검증과 실제 운영 Postgres 검증을 구분한다. 운영 쓰기는 하지 않았다.

## 근거
NSCA Lincoln/Ill/Ibrahim 2023:
https://www.nsca.com/education/articles/ptq/teaching-resistance-training-movement-patterns/
본문과 공개 PDF의 Exercise progressions, Instruction and cueing, Feedback 확인.
원문 Figures1/2/3의 예시를 지도자 동반 연습 기록으로 연결한다.
개입 실험이나 앱 단독 효과 검증 자료가 아니다. 원 시연 이미지는 복제하지 않는다.
지도자 동반 조건과 기록 상태 전이는 제품 정책이다. 운동의 의학적 적합성을 인증하지 않는다.

## 적대적 검토
1. 지도자가 필요한 경로만으로 '혼자 처음 온 사용자' 요구를 충족하지 못한다.
2. 완료 버튼/연습 횟수를 기술 숙련 인증으로 사용하지 않는다.
3. 낮은 외부 중량이 낮은 동작 난이도를 뜻하지 않는다.
4. 교육 카드3개를 루틴3개로 세지 않는다.
5. 기존 초급 두 일정은 같은 연구이며 중급 Helms는 SB만 포함한다.
6. 공급 숫자를 채우려고 PER의 front-squat 치환 문제를 승인하지 않는다.

## 공급 응답 수정
/v3/routines.supply_audit:
선택안 수, 근거 연구군 수, 완전한 SBD 포함 여부, 공급 공백을 별도로 반환한다.
evidence_family_count는 연구 보고를 묶은 숫자이지 품질 점수가 아니다.
LIMITED_PROGRAMME_DIVERSITY는 현재 단일 연구 편중에 대한 설명이지 '최소2편이면 충분' 기준이 아니다.
supply_complete=false는 현재 검토 결론이며 테스트 통과로 자동 true가 되지 않는다.
교육 별도 경로와 지도자 조건을 반환한다.
