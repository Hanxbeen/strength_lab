## 현재 프로그램을 대입한 결론
| 자료 | 제공 역할 | 입력/제약 | 서비스 공백 |
| --- | --- | --- | --- |
| Helms | 스쿼트/벤치의 %1RM·RPE 실행 비교 | 기존 연구 재현 범위, 측정 1RM, 휴식·준비 선택 | 데드리프트를 포함한 기본 SBD 프로그램 아님 |
| PER SBD | 10주 원문 템플릿의 내부 SBD 조정안 | 원문 종목과 매핑 차이 명시·수락, SBD 1RM | 종목 모순·준비/본세트 구분, 일반 기본안 공개 적합성 미해결 |
| METD | 경험자 대상 6주 저용량 세 구성 | 저항훈련/PL/RPE 경험, MAX의 당일 직접 중량, AMRAP의 노력도 종료 | 초보 기본안 아님; 일반 훈련 대비 최적성 근거 아님 |

현재 자료를 더 쉽게 실행시켜도 기본 SBD 프로그램 공급 공백은 남는다. readiness를 추천으로 이름만 바꾸지 않는다. 이후 원문 확보는 이 공백을 채우는 프로그램을 대상으로 하며, 보완이 안 되면 공개하지 않는다.

## API 계약
POST `/v3/programme-readiness`: source_id/version/arm/created_at, profile/setup/max_record_ids를 받는다. 기존 등록 기록은 인증 소유자의 것만 참조한다. 입력 상태·내부 접근 권한·추천 상태를 분리한다. 누락 필드는 사용처별로 한꺼번에 반환한다. 값/연구 범위 판단은 실제 생성에 쓰는 동일 어댑터를 호출한다. 새 검증 공식이나 의학적 판정을 복제하지 않는다.

- input_status: needs_input / invalid_input / outside_supported_scope / ready.
- access_status: not_released / internal_preview_allowed.
- recommendation_status: not_assessed. ready는 입력이 충분하다는 뜻이지 안전·효과·추천 적합성이 아니다.
- can_create_instance: ready이며 서버 내부 허용 계정인 경우만 true.
- missing_inputs/next_actions: 누락 입력, 실측 최대중량 등록/선택, 입력 수정, 범위 확인 또는 내부 실행.
- session_start_inputs: RPE 기반 직접 중량은 해당 회차 시작 시 입력. 미리 임의 비율을 채우지 않는다.
- not_assessed: 현재 통증/상태, 실제 장비 보유, 개인 일정 적합성, 장기 결석 재개 처방 등 미판정 범위를 명시.
- 결과는 저장하거나 실행 권한 토큰으로 쓰지 않는다. 생성 시 최신 자료·권한·입력을 다시 확인한다.

GET `/v3/programme-instances/{id}/next-session?at=...`: 새 인스턴스를 만들지 않고 다음 행동을 반환한다. workout_open이면 기존 운동으로, 모든 회차 종료면 평가로, 평가가 있으면 종료 결과/다음 프로그램 선택으로 연결한다. 날짜가 이르면 가능한 가장 이른 시각을 반환한다. schedule_available은 시간 제약 충족만 뜻한다. 통증이나 긴 결석 이후 수행 가능성을 승인하지 않는다.

## 일정 정책
원문 세션 목록·순서와 제품의 최소 시작 간격을 분리해 programme-schedule-v1로 고정한다. 신규 인스턴스는 정책을 포함한 버전으로 생성하고 세션에도 해당 정책을 보존한다. 기존 인스턴스는 이전과 동일한 명시적 호환 정책을 사용한다.

지원하는 세 어댑터는 주 3일 상대 일정이다. 현재 48시간 최소 간격은 제품 정책이며 연구가 증명한 안전 임계값으로 표현하지 않는다. 늦어진 날짜는 허용하되 회차 순서를 유지하고 미수행 분량을 다음 회차에 더하지 않는다. 세션 전체 생략/다른 주간 일정/긴 결석 재처방은 아직 구현하지 않는다. 주 6회 연구를 추가할 때 현재 규칙을 그대로 적용하지 않도록 별도 일정 정의가 필요하다.

## 실패 시나리오 / 인수 조건
| 상황 | 응답·행동 | 금지 |
| --- | --- | --- |
| 1RM·설정 없음 | 필요한 입력 목록 | 0 또는 평균 중량으로 채움 |
| 다른 계정의 1RM ID | 사용 가능한 등록 기록 없음 | 존재/수치 노출 |
| 연구 재현 범위 밖 | 지원 범위와 입력 확인 | 위험하다/효과 없다 단정 |
| 일반 계정이 모든 입력 완료 | ready + not_released | 사전 확인으로 공개 차단 우회 |
| 확인 후 자료 사용 중지 | 생성 시 다시 거부 | 이전 readiness를 승인 토큰으로 사용 |
| 하루 이른 다음 회차 | waiting + earliest_start_at | 무응답 오류 또는 간격 자동 축소 |
| 진행/중단 중 운동 존재 | 기존 운동으로 이동 | 다음 회차 중복 시작 |
| 며칠 지연 | 기존 순서·목표 유지, 시간 차이 표시 | 놓친 양을 자동 가산 |
| 모든 회차 종료 | 평가 안내 | 신규 회차 생성 |
| 프로그램 평가 완료 | 기록/다음 선택 | 종료 프로그램 재개 |

## 다음 단계와 중단 기준
1. 이 계약으로 기존 프로그램의 입력/상태/다음 행동을 테스트한다.
2. 기본 SBD 공급 공백을 채울 독립 연구의 실제 처방 표·진행 규칙을 확보한다. 전용 설명 API와 추상 프레임워크 확장은 보류한다.
3. 검토된 제공 범위·책임·서버 배포/저장 경계를 확정한 뒤 iPhone에 연결한다. 현재는 배포 주소와 동기화 경계가 미확정이며 완료라고 보고하지 않는다.
4. 입력부터 다음 회차까지 실제 사용성을 확인한다. 실행 테스트 통과를 효과 검증으로 바꾸지 않는다.
