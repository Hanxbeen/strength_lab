# 루틴 콘텐츠·진행·완료 분석 인수

2026-10-27. 범위: 공개 훈련 선택안 10개와 별도 입문 학습 1개. 이번 작업은 화면 디자인 이전에 소비 가능한 콘텐츠와 API 계약을 보완한다.

## 완료 조건과 검증 순서

| 영역 | 완료 조건 | 확인 방법 |
| --- | --- | --- |
| 공급 | 공개 선택안과 사용 종목 전부 연결 | 실제 options 응답과 종목 집합 대조 |
| 동작 | 장비·시작 자세·순서·호흡·실수·중단·시연 출처 | 종목별 필수 필드 및 출처 확인 |
| 루틴 | 대상·적용 조건·구성·부하·휴식·진행·제품 조정·한계 | 원 정의와 설명 projection 비교 |
| 연구 차트 | 보고 수치·단위·집단·시점·출처, 또는 미제공 이유 | 원문과 독립 대조, 연구/개인 차트 분리 |
| 진행 | 첫 중량·목표 미달·변경·건너뜀·통증·중단·재접속 | 안내의 행동과 실제 API 지원 대조 |
| 세션 결과 | 목표/실제·미기록·변경·휴식·다음 행동 | 정상·변경·중단 반례 실행 |
| 프로그램 결과 | 회차별 관찰·시작/종료 비교 조건·한계·다음 선택 | 미측정·추정·다른 조건에서 변화량 비노출 |

## 판단 원칙

- 연구 직접 보고, 교육 자료의 종합, 제품 운영 규칙, 사용자 자기보고, 실제 수행 기록을 구분한다.
- 원 연구 정의를 변경하거나 새 훈련 선택안을 공개하지 않는다.
- 없는 연구 수치는 만들지 않는다. 연구 집단 평균을 개인 목표선으로 사용하지 않는다.
- 미기록은 0이나 실패로 채우지 않는다. 수행률·관찰 볼륨은 효과 달성률이 아니다.
- 종료된 운동의 재개, 임의 종목 대체, 자동 다음 주기 처방은 지원한다고 안내하지 않는다.
- 실제 로그인·Postgres 저장·계정 간 격리·아이폰 상호작용 검증은 사용자 결정대로 최후 단계에 남긴다.
- 로컬 인증 대역·SQLite 검증은 실제 서버 쓰기 검증으로 보고하지 않는다.

## 작업 상태

구현 연결 완료. 전체 회귀 검사에서 발견된 이전 입문 경로 호환 문제를 수정하고 재검증 중이다.


## 소비 API와 데이터

| 화면 | 응답 위치 | 내용 |
| --- | --- | --- |
| 루틴 상세 | `/v3/routines`의 `routines[].experience` | 대상·구성 이유·일정·설정·종목 안내·연구 차트·진행 안내·한계 |
| 선택한 루틴 | `/v3/programme-instances/{id}`의 `experience` | 현재 카탈로그가 아닌 선택 당시 고정 source 기준 |
| 입문 상세 | `/v3/entry/learning-paths`와 목록의 `learning_paths[].experience` | 입문 동작 3종·대상 바벨 동작·선택적 첫 중량·다음 행동 |
| 진행·복원 | `execution.experience` | 동작 안내·상태별 행동·이벤트 경로·중단/재접속 안내 |
| 오늘 결과 | `/v2/workouts/{id}/result`의 `analysis` | 기록 세트·목표와 차이·미기록·해석 한계·다음 행동 |
| 루틴 종료 | evaluations의 `analysis` | 회차별 종목 기록량·미측정/비교불가 사유·다음 선택 |

`experience-content-v1`은 교육·표시용 버전이다. 연구 정의·원장 snapshot·event 및 기존 평가 payload를 변경하지 않고 응답에 부가한다. 기존 평가 재조회는 `history_inputs`의 event revision과 digest에 고정되므로 나중에 입력한 사유가 당시 평가에 혼입되지 않는다.

동작 안내는 바벨 백스쿼트·벤치프레스·데드리프트·프런트스쿼트·스탠딩 숄더프레스와 의자 일어나기·벽 밀기·벽 힙힌지의 총 8종이다. 교육 요약은 원 훈련 논문이 직접 검증한 자세 교육이라는 뜻이 아니다. 앱에서 시연을 열 때는 새 `experience`의 안내 링크를 사용한다. 연구 정의에 고정된 이전 출처 문자열은 버전 보존을 위해 변경하지 않는다.

## 연구 차트 표시 규칙

| 근거 | 연결 선택안 | 데이터 | 반드시 표시할 한계 |
| --- | ---: | --- | --- |
| Helms 2018 | 2 | 8주 1RM 변화량 평균·표준편차, 6점 | 변화량 SD이며 CI·개인 예측범위 아님. 벤치 사후값 불일치로 전후값 재구성 금지 |
| METD 2021 | 3 | 6주 SBD 합계 변화의 사후분포 최빈값·95% HDI, 4점 | 연구3/4 별도 패널. 4군 동시실험 아님. 관측평균 아님 |
| PER 2018 | 1 | Table4 개인별 SBD 전후 1RM, 18점 | 합계 모순으로 개별 종목만. 사후 대회조건과 작은 표본. 프런트스쿼트 효과 아님 |
| Petrizzo 2018 | 2 | 참여자 진행 인원, 4범주·분모58 | 근력 변화량이 아님. 주2/3회 효과 비교가 아님 |
| SBD 제품 종합 | 2 | 직접 실험 없음으로 차트 미제공 | 기존 근거가 정확한 제품 구성을 실험했다는 주장 금지 |
| 입문 학습 | 별도1 | 교육 경로로 효과 차트 미제공 | 자세 인증·근력검사 아님 |

`available=false`이면 `reason`과 한계를 표시한다. 빈 배열은 변화량0이 아니다. 연구3/4는 `panel_id`를 보존하고 통계 종류·단위·시점·표본·원문 위치를 함께 표시한다. 사용자 곡선과 연구 집단을 같은 성장 목표선으로 합치지 않는다.

회차별 `observed_volume_kg_reps`는 기록된 중량×횟수의 합이다. 전부 미기록이면 null, 실제0회는0이다. 누락 세트·구성·횟수·종목이 다른 회차를 효과 우열로 해석하지 않는다.

## 재현

```sh
.venv-coaching/bin/python -m scripts.fetch_content_sources
.venv-coaching/bin/python -m scripts.verify_content_experience
.venv-coaching/bin/python -m scripts.verify_tests
```

인수 스크립트는 공개10안의 미리보기→시작→중량/횟수 변경→종료→세션 분석→프로그램 평가→재조회와 입문 통증 중단을 확인한다. 원 데이터 fixture·인증 대역·임시SQLite를 사용한다. 실제 Supabase 카탈로그의 이번 재조회나 서버 Postgres 쓰기 검증은 포함하지 않는다.

## 남은 별도 인수

새 콘텐츠를 소비하는 화면·와이어프레임, 실제 로그인·Postgres 저장/격리·실기기 상호작용은 이번 완료 조건 밖이다. 운영 배포·main 병합·아이폰 설치도 수행하지 않는다. 정적 분석이나 테스트 통과를 실제 사용자 사용성 또는 훈련 효과 검증으로 표현하지 않는다.
