# 기존 근거 자료 점검과 문헌 구축 착수
날짜: 2026-10-12 KST. 기준 저장소: 8284c65, codex/ux-foundations-v2.
범위: 기존 문서·저장소 정적 점검. 이번에 DB 실조회, 배치 실행, 전체 원문 재검토, 과학적 승인 또는 처방 변경을 수행하지 않았다.

## 결론
현재 자산은 문헌 검토 설계와 수집·구조화 시제품이다. 서비스의 코칭 질문 전체를 뒷받침하는 검수 완료 근거 체계가 아니다. 먼저 질문별 문헌 검색·추출·종합을 수행한다. API 확장이나 후보 개수 증가는 후순위다.

## 문서 회수
SERVICE_PRINCIPLES 0.2, EVD/RUN/PER/OPS 0.2, AUDIT 0.1을 현재 문서 내용으로 회수했다. 기존 저장소에 없던 여섯 문서를 이 폴더에 보존한다. 설계안이라는 원래 상태를 유지하며 임의 승인하지 않는다.
기존 docs/RESEARCH_ENGINE_ADVERSARIAL_REVIEW.md는 1a82ca0 시점이다. 당시 항상 runnable=false 지적을 이후 v2 엔진에도 그대로 적용하면 안 된다. SOURCE_ENGINE_V2.md와 seed-definitions가 별도 성공 경로를 보여준다.

v1 후보: PMC11140948(하프 스쿼트/트랩바), PMC8041766(파워리프터 세트 구성), PMC7126254(벤치프레스 템포/1RM).

즉 v1과 v2의 3편은 같은 목록이 아니다. 여러 군을 여러 독립 연구로 세지 않는다.
PMC6974452 ISO군은 미지원 등척성 이벤트 때문에 제외돼 있으며, TRAD만으로 등척성 중재의 효과를 검증했다고 말할 수 없다.
PMC8041766은 공통훈련·추가훈련의 완전한 구성 문제가 기존 검토에 기록돼 있어 우선 재검토 대상이다.
이 설명은 저장소 기록에 대한 점검이며 이번 원문 독립 대조 결과가 아니다.

## 수집기에서 확인한 공백
- scripts/research_batch.py는 단일 trial 중심 검색식, 관련성 순위 상위 제한, SBD 문자열 필터를 사용한다. Q01~Q12 각각의 검색이 아니다.
- scripts/research_oa_v2.py는 제목의 systematic.review/meta.analysis를 제외한다. 실행 중재 선별에는 쓸 수 있으나 근거 종합 자료까지 수집하는 유일한 경로로 쓰면 안 된다.
- 공개 XML 접근 가능성을 후속 선별 조건으로 사용하므로 접근 편향을 별도 관리해야 한다.
- retrieved_ids는 반환 ID 수다. 전체 검색 결과 수나 전체 검토 완료 수가 아니다.
- .github/workflows/research-discovery.yml에 월요일 03:17 UTC 예약과 --persist가 있다. 기본 브랜치 존재·시크릿·실제 실행 성공은 이번에 확인하지 않았다.
- 주간 파일은 기존 발견/적재 경로다. 질문별 신규·정정·철회 영향 알림 체계가 완성됐다는 증거가 아니다.
- 관련 이름 EvidenceClaim/CoachingQuestion/DecisionRule의 저장소 검색에서는 해당 경로 내 일치가 없었다. 모든 의미상 유사 구현 부재를 증명하는 검사는 아니다.

## 착수 순서와 결과물
1. Q01/Q02/Q03/Q04/Q11부터 질문별 대상·비교·결과·검색식을 고정한다. 이어 Q05~Q10/Q12를 채운다.
2. 기존 후보를 유지하면서 질문별 종설과 직접 실험을 병렬적인 자료 유형으로 수집한다. 종설 포함 연구를 독립 증거로 중복 계산하지 않는다.
3. SearchRun과 Report 목록, 선별 사유, 원문 미확보·보충자료·정정 연결을 저장한다.
4. 원문 전체의 대상자·공통훈련·군별 구성·진행·실패 규칙·결과·한계를 추출하고 원문 위치를 연결한다.
5. 질문별 EvidenceClaim과 적용 조건을 정리한 후 DecisionRule 후보를 만든다. 입력 빈칸이나 product_policy 명칭으로 검토를 우회하지 않는다.
6. 처방 근거 종합과 별도 확인 전에는 API 공개 상태를 올리지 않는다.

이번 작업으로 배치·처방·DB·사용자 기록은 변경하지 않았다. 전체 문헌 검색이나 독립 전문가 검토가 완료됐다고 주장하지 않는다.
