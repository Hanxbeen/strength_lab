# 릴라 Phase 1 — Character Master / 승인 대기

> 제품: **무게꾼** · 마스코트: **릴라 (Lila)** · 작성: 2026-10-09
>
> 상태: **DESIGN REVIEW — NOT APPROVED**. Phase 2(Rive 파츠·리깅·상태 머신 구현)는 사용자 명시 승인 전 시작하지 않는다.
>
> 기준 원화: 사용자가 선택한 3D 릴라 성장 시트(2026-10-09 대화에 첨부한 이미지, 차콜 털/아이보리 얼굴, 정면 6단계). 뒤이은 신규 생성 시트는 **제안 이미지**이지 공식 원화가 아니다. 원본 이미지 바이너리는 아직 이 저장소에 포함되지 않았다.

## 0. 목표 / 허용 범위

- **릴라의 고유 외형과 6단계 성장에 대한 디자인 계약**을 확정한다.
- 원본을 그대로 애니메이션으로 변환했다고 주장하지 않는다. 스틸 일러스트만으로 Rive 관절/가려진 면/회전 시점이 만들어지는 것은 아니다.
- Phase 1 산출물: 디자인 명세, 구조화된 토큰, 감정·레벨별 변형 규칙, 시각적 검수 게이트.
- 범위 제외: 실제 Rive 파일/리그, SwiftUI Rive 통합, 운동 동작/운동별 물리 애니메이션, 앱 아이콘 최종 교체, 앱 설치.

## 2. 머리 위 털 — 승인 선택지 A/B

**A. 짧게 누운 새싹털 [권장]**
- 가운데 윗부분에 붙은 **2~3가닥의 가느다란 잔털**. 납작하고 짧은 물방울형으로 살짝 누워 있고 덩어리나 공처럼 쌓이지 않는다.
- 머리 높이 대비 돌출 높이는 약 **3~5%** 내외. 방향은 옆으로 흐르는 미세한 굴곡.
- 머리 기본 실루엣과 이질감 없이 연결. 정면, 측면, 3/4 시점에서 방향을 유지.
- 불합격: 3층 찐빵/똥머리/뿔/새 둥지/포크처럼 큰 솜뭉치/별도 부착된 공 3개.

**B. 무털**
- 이마에서 정수리까지 **끊김 없이 둥근 한 덩어리**.
- 단순하고 읽기 좋으나, 원본의 고유성·귀여움이 약해질 수 있다.

Phase 1에서 **A/B 중 사용자가 선택한 1안만 마스터에 채택**. 나머지는 실험용이며 섞어 쓰지 않는다.

## 3. 성장 규칙: Lv.1 ~ Lv.6 (고정된 얼굴 ID)

**전시용 성장 시트**는 6개 전신 캐릭터, 동일한 정면 카메라/높이 기준/비조명 환경/시선/발 수평선, 동일한 눈코 배치, 손은 전부 비움. Lv.6 외 왕관·망토·덤벨·바나나·원판·모자·기타 소품 **전부 금지**. 초기 아기는 앉아도 되며 Lv.2부터 직립.

| 레벨 | 정체성 | 머리와 몸 비율 및 자세 | **단계별 고유 체형 요소** |
|---|---|---|---|
| Lv.1 아기 릴라 | 시작·호기심 | 앉음; 머리가 유독 크고 사지가 짧음 | 목이 거의 안 보이는 아기 실루엣, 발끝 노출 |
| Lv.2 새싹 릴라 | 첫 직립 | 두 발로 섬; Lv.1 대비 팔다리 명확히 길어짐 | **작고 둥근 몸통, 얇은 어린 팔/다리**. Lv.3 근육 덩치 금지 |
| Lv.3 성장 릴라 | 균형·습관 | 안정적으로 직립; 머리 대 몸 비율이 성숙해짐 | **어깨가 처음으로 넓어지고 가슴 볼륨이 명확해짐** |
| Lv.4 단단한 릴라 | 축적 | 직립; Lv.3보다 발과 허벅지 고정감 증가 | **전완·상완·허벅지 두께 증가**, 가슴 형태/어깨 곡률도 달라짐 |
| Lv.5 숙련 릴라 | 묵직한 강함 | 가장 균형 잡힌 성숙한 몸; 과시적 자세 아님 | **넓은 어깨, 굵은 팔, 두툼한 승모, 안정된 하체**; 팔은 몸 옆으로 내려야 체형 비교 가능 |
| Lv.6 무게왕 릴라 | 성취를 상징 | Lv.5와 같은 성숙한 근육·얼굴 비율. **Lv.5보다 작아지지 않음** | Lv.5 체형 기반, 왕관 + 빨간 망토만 추가. 운동 중 왕관/망토 자동 제거(Phase 2 규칙) |

- 성장의 비교 기준은 **실측 키(cm), 중량(kg), 임의 80/90/100% 스케일이 아님**. 승인된 시각적 비율을 Phase 2 리그 설계 시 정량화한다.
- Lv.2→3: 어깨·가슴이 생김. Lv.3→4: 팔·허벅지 두께. Lv.4→5: 등·어깨 폭과 상체 무게중심. 단순 동일 모델 등비 확대는 **실패**.
- 모든 레벨의 얼굴 인식 형태·눈 간격·코/귀 위치는 성장에 따른 크기 조정만 한다.
- 초기 캐릭터를 운동 능력이 부족하거나 창피한 존재로 표현하지 않는다.

## 4. 감정 문법 — 눈, 자세, 기호만; 입 없음

| 상태 ID | 눈 상태 | 자세/동작 예정 | 기호(필요 시) | 금지 |
|---|---|---|---|---|

| blink | 눈이 잠시 가늘어짐 | 머리 고정 | 없음 | 눈 구조 바뀜 |

| surprise | 세로 눈을 약간 크게 | 짧은 머리 뒤로 움직임 | ! | 과장된 공포 |
| curious | 양눈의 시선이 옆으로 | 살짝 기울임 | ? | 큰 흰자 눈 |

| focus | 눈 폭 살짝 축소 | 안정된 정면 집중 | 작은 선/점 | 화난 눈썹 |
| sleepy | 눈이 반쯤 감김 | 어깨 낮춤 | zZ | 실신처럼 보이기 |
| confident | 기본 눈 | 가슴 약간 펴기 | 반짝임 선택 | 도발·과시 |
| celebrate | 밝은 눈 | 짧은 양손 상승 | 별/컨페티 | 입/혀 등장 |
| warning | 짧은 눈깜박임 | 주의 표정 + 정지 | ! 경고 | 사용자를 꾸짖기 |

UI 기호는 **얼굴 바깥 독립 레이어**이며 상태 머신 제어 대상(Phase 2). 폰트 글리프/벡터 도형으로 구현 가능하도록 간단하게 디자인한다. '골뱅이'는 입이 아닌 눈/머리 주변 심볼로 처리한다.

## 5. 리깅 이전부터 필요한 시점

- 마스터 정면 (표준 아이콘용), 정면 3/4 좌·우, 측면 좌·우, 후면.
- 이마/주둥이 분리감, 귀 두께, 손과 발의 체적을 일관성 있게 표현.
- 세로 타원 눈/콧구멍 2개는 얼굴에 귀속; 기호·왕관/망토·장비는 분리 레이어의 향후 후보.
- 캐릭터 최초 시안은 3D풍 스틸일 뿐, 아직 .riv 바이너리·본 리그·감정 모션·운동 애니메이션이 아니다.

## 6. 자동/수동 검수 Gate — Phase 1

Gate는 **각 레벨/각 털 후보/각 시점별로 검사**한다. 전체 평균이 아니라 항목 단위에서 필수 하나라도 실패하면 **승인 보류**.

**G1 구조:** 6레벨 누락 없음, Lv.1~5 장신구/손 소품 없음, Lv.6 왕관·망토만 있음.

**G2 식별:** 한 캐릭터 얼굴처럼 보이며 원본과 핵심 생김새 유지(귀·주둥이·눈·코·피부 위치). 원본과 비교된 실사/렌더 기준 이미지가 필요.

**G3 성장:** 레벨 2~5 각각의 근육·골격 차이가 뚜렷함. Lv.6이 Lv.5보다 작거나 약해 보이면 실패. 표준화된 시트 카메라 필수.

**G4 미니멀 얼굴:** **눈2+콧구멍2**, 입/혀/치아 없음. 눈은 기본 세로 타원. 감정 기호는 주변 레이어로 별도 취급.

**G5 머리털:** 옵션 A(짧고 누운 2~3가닥) 또는 B(없음)만 허용; 동글동글 쌓인 만두/공/뿔/물방울 3층 금지.

**G6 색/질감:** 매트 차콜/아이보리/sRGB, 3D 입체감은 유지. 청록색/초록빛/과도한 유광 금지.

**G7 접근성·확장:** 64px와 120px 축소에서 눈/코/실루엣 식별; 시점별 동일 인상; 레벨/감정 구분. Rive 실제 모션, 작은 기기 화면의 실제 구현은 Phase 2 이후 별도 판정.

**G8 금지된 임의 규격:** 키(cm)·측정하지 않은 체중/근육량 수치·의도되지 않은 소품·의도되지 않은 기능 상태/보상 추가 금지.

**Phase 1 통과 요건** = G1~G8 만족 + 머리털 A/B 확정 + 마스터 얼굴 시점별 승인 + 6레벨 외형 사용자 승인. 현재는 **미승인**.

## 7. 사용자의 승인을 요청할 결정 (Phase 2 게이트)

1. 머리털: A(짧게 누운 2~3가닥) vs B(아예 없음).
2. 고정 얼굴: 세로 타원 눈 2개·콧구멍 2개·입 없음, 넓은 아이보리 주둥이, 원본 고릴라 인상.
3. 성장 차이: Lv.2→3 어깨/가슴, 3→4 팔다리, 4→5 등/어깨 폭, Lv.6 장식만 추가.
4. 색상: 거의 블랙인 차콜 `#2A2A2A` + 아이보리 `#F3E7DB` (현재 임시 샘플).
5. 이 정의를 Phase 2 Rive용 분리 파츠 계약으로 넘길지.

**명시적인 승인 후에만 Phase 2 시작.** Phase 2 작업은 앱 마스코트와 아이콘의 실제 교체 작업과는 별도로 검증·배포한다.
