## 반영한 코드

- BrandUI를 의미 기반 토큰 단일 출처로 유지. 파란 활성 CTA, 별도 비활성 배경·글자, 최소 CTA 56pt/행 48pt, 기존 여백·반경·Dynamic Type 유지.
- Lucide 10개 SVG template 자산과 라이선스. 활성 탐색·운동·입력 화면의 커스텀 SF 아이콘 교체.
- 홈/루틴/기록 3탭, 기록 안 운동/성장 전환. 설정은 홈 상단.
- 건너뛸 수 있는 3장 소개, 재노출 방지, 설정에서 다시 보기. 별도의 닫을 수 있는 홈 도움 카드.
- 홈 진행 운동 우선, 실제 최대 중량·종목별 월간 비교·최근 운동. 누락 종목과 비교 불가 상태 분리.
- S/B/D 종목별 최대 중량 입력, 직접 입력과 ±조절, 키보드 툴바 다음, 부분 입력·검토·일괄 원자 저장. 저장 실패 시 초안 유지.
- 표시 단위 kg/lb 설정과 단일 변환 상수. 홈·운동 입력/결과·기록 수정·성장 차트·기존 측정 가이드 변환. 기존 저장값·스키마는 변경하지 않음.
- 수정하지 않은 기존 세트의 lb 표시값을 다시 kg로 저장하지 않음. 최대 중량 입력은 기존 값을 자동 재저장하지 않음.
- 공개 루틴 목록에서 DEMO 제외, 홈의 기록 연습으로 이동. API 로딩/실패/빈 목록 상태 구분. 연구 제목을 임의 ‘맞춤 루틴’ 문구로 바꾸지 않음.
- 임의 65% 시작 중량 자동 제안 제거. 마지막 세트 후 불필요한 타이머 생성 방지. 휴식 일시정지를 ‘타이머 일시정지’로 명확히 표기.
- 실제 1RM과 추정 1RM 성장 차트를 별도로 표시. 기존 이력의 계획/실제 휴식 데이터가 없음을 명시.

## 아직 미완료 — 다음 데이터 계층 작업

1. 명세 18장의 schema v2, 변환 전 백업·참조 검사·버전 충돌 정책·클라우드/백업 호환.
2. 불변 계획 스냅샷, 수행 세트 상태/수정 이력/건너뛰기, 남은 세트 적용과 선택적 이유.
3. 실제 RestInterval 이력, 세트 간 휴식 횟수·실제 경과·연장/일시정지 이벤트·복구 확인. 이번 변경은 기존 현재 타이머만 사용한다.
4. 결과의 계획 대비 중량/횟수/휴식 차트, 수행량 분석. 기존 데이터에는 임의 분모를 만들지 않는다.
5. 추정 StrengthRecord 저장·근거 정보, 회수된 공개 버전 정책과 스냅샷 재개.
6. 연구 검수 20편 목표 및 승인 데이터 게시 연결. 현재 공개 0건을 허위 루틴으로 채우지 않았다.
7. 릴라 앱 아이콘 양옆 프레이밍 조정, 가로 눈금 선택 UX, 40개 전체 상태의 화면 검수.
