- programme-schedule-v1: 원문 세션 목록/순서와 제품의 상대 일정·최소 48시간 간격을 분리했다. 신규 인스턴스/세션에 고정하고 프로그램 버전에 반영한다. 기존 인스턴스는 기존 동작과 동일한 호환 정책으로 처리한다.
- 아직 주 6회/자유 순서/전체 회차 생략/긴 결석 후 자동 재처방을 지원하지 않는다. 기존 간격을 느슨하게 바꾸지 않았다. schedule_available은 일정 조건만 충족했다는 뜻이다.
- 일반적인 기본 SBD 프로그램의 근거·공급 공백은 여전히 남는다. 이번 API 계약을 추천 엔진 완성으로 보고하지 않는다.
- 최종 Python 회귀 테스트 174개 통과, 건너뜀 없음. 신규 5개 테스트에서 세 자료의 사전 확인, 소유자 격리, 확인 후 자료 중지, 정책 고정/호환, 대기·복귀·지연·평가 상태를 검증했다.

## SBD 공급 데이터 확장 — 2026-10-15 후속
- METD 2021 (PMC8435792) 원문/출처를 보존하고 MAX, MAX_BOFF, AMRAP 세 구성을 6주·18회차 정의로 추가했다. 한 논문의 두 실험/세 구성이지 논문 세 편이 아니다.
- 각각 본세트 36/108/36개. AMRAP 준비 108세트를 본세트로 합산하지 않는다.
- MAX 시작 중량은 RPE에 맞춰 직접 입력한다. 백오프는 완료한 실제 단일 반복의 80%이며 기준 부재 시 직접 선택/생략. AMRAP은 고정 목표 반복수가 없어 전체 횟수 달성률을 null로 반환한다.
- execution-ledger-v3와 metd-2021-v1 어댑터로 기존 수행·휴식·사유·종료 평가에 연결했다. 이전 v1/v2 기록 계약은 유지한다.
- 원문 휴식은 훈련과 측정을 구분했다. 훈련 휴식/일부 준비운동/장비 반올림/앱 종목 순서는 명시적 선택 또는 제품 규칙이다.
- DB에 신규 불변 정의를 저장했다. 신규 coaching_programme_catalog_v2 RPC는 활성 정의 3개(Helms/SBD PER/METD)를 다루며 이전 RPC의 범위는 유지한다. 공개 앱 루틴 승인 또는 iOS 연결 완료가 아니다.
- 전체 Python 회귀 테스트 169개 통과(건너뜀 없음). 세 구성 모두 18회차 수행→종료 평가 검증. 실제 HTTP 조회의 정의/해시 일치 확인 후 DB에서 받은 자료로 신규 11개 테스트 재통과.
- 상세: coaching-specs/12_METD_SOURCE_EXPANSION.md. Colquhoun 2017/2018은 핵심 표와 원문 대조가 남아 실행 정의로 임의 확장하지 않았다.
- 다음은 독립적인 기본 SBD 프로그램 근거/처방 표 확보다. 같은 연구진의 소표본 저용량 연구만으로 서비스 전체를 대표하지 않는다. UI 변경은 계속 보류한다.
