# 연구 기반 실행 엔진 재검토

검토일: 2026-10-11. 대상 구현: 1a82ca0.
상태: 설계 제안과 결함 검토. 실행 엔진 구현/검증 완료 문서가 아니다.

## 판정

현 구현은 수집 및 부적합 사유 반환 도구다. 서비스의 원천인 근거-처방-변형 엔진으로 출시할 수 없다.
자동 공개 성공 경로가 없으며, 논문 수집량을 늘려도 이 문제는 해결되지 않는다.

## 코드 및 재현 확인

1. scripts/research_automatic_assessment.py: 모든 결과 runnable=false, build의 runnable_count=0. 정상 원문도 MISSING_PRESCRIPTION으로 차단.
2. scripts/research_oa_v2.py: 제목에서 systematic.review/meta.analysis를 제외. 처방 원칙을 확보하는 별도 근거 합성 경로가 없음. 예시 2023 Currier NMA 제목을 넣으면 excluded_off_topic_or_acute.
3. scripts/research_protocol_audit.py: regex 첫 매치와 앞뒤 일부 문맥을 추출. 군/주차/세션/공통훈련 관계를 보존하지 않음. table_rows는 rowspan/colspan/header 참조를 보존하지 않음.
4. scripts/research_gold_eval.py: 고정 표 행의 셀 일치만 검사. 재현 실험에서 헤더 Pre/Post를 뒤집어도 동일하게 통과. 독립 이중 검수도 아님.
5. scripts/research_pipeline.py: gold_eval 기본 경로는 data/research/protocol_audit.json. 해당 실행의 folder/protocol_audit.json 검증이 아님.
6. 앱 TrainingExercise는 종목마다 sets/reps/rest만 표현. 주차별/세트별 부하, RIR/RPE, 클러스터, 보조운동 맥락 표현 불가.
7. public_catalog의 공개 플래그·해시 유무 검사는 처방 충실도나 과학적 타당성 검사가 아님.

실제 원문 대조: PMC8041766 Training program 절은 공통 파워리프팅 주2일 + 실험군 추가 저항훈련 주3일, 추가 세션의 8종목을 기술한다. 표4만 가져오거나 SBD만 남기면 원 연구 중재를 재현한 것이 아니다. 이 논문을 새롭게 실사용 승인하지 않았다.

## 제품 정의

검증된 근거 범위 안에서 사용자의 시간·장비·훈련 경험·기록에 맞는 훈련을 결정하고, 모든 선택의 이유와 한계를 추적할 수 있는 서비스.
개수는 처리량 지표다. 성공 기준은 지원하는 사용자 상황의 범위와 각 결정의 설명 가능성이다.
'모든 운동 맥락'을 유한 개 논문으로 입증한다는 주장은 금지한다. 초기 범위는 건강한 성인의 SBD 중심 근력 훈련으로 한정하는 안을 권고한다.

## 데이터는 세 계층

A. 원문 중재: Study -> Arm -> Week/Phase -> Session -> Exercise -> Set/Cluster. 공통훈련/추가훈련/보조운동/순서/ROM/템포/휴식/강도/진행·실패·중단 조건/측정법/대상자 조건까지 보존한다.
B. 근거 규칙: 질문(PICO), 대상자, 목표, 비교, 효과와 불확실성, 한계, 독립 연구 집합, 허용 범위, 상충 근거, 출처를 기록한다. 메타분석과 원 연구를 이중 계수하지 않는다.
C. 제품 정책: 장비 반올림, 시간 제약, 미수행·중량 하향 처리, 설명 문구 등 제품 결정. 논문에 없는 규칙은 제품 정책으로 표시한다.

각 값은 value/unit/scope/provenance/status(source_reported, derived, product_policy, not_reported, not_applicable)를 갖는다. 누락을0이나기본값으로 바꾸지 않는다. 보정 계산과 원문 수치는 별도 저장한다.

## AI 없는 실행과 AI 없는 신규 논문 해석을 분리

운영 요청 처리, 프로그램 편성, 중량 환산, 규칙 적용, 설명 생성, 배치 검증은 구조화 데이터와 결정적 코드로 구현한다. AI 호출0을 실제 네트워크 차단 상태에서 시험한다.
임의 신규 논문의 자유문장·표·보충자료를 항상 정확히 해석하는 범용 자동화는 현 근거로 약속할 수 없다. AI를 넣어도 정확성이 자동 보장되지 않는다.
초기 참조 데이터와 source adapter의 정확성을 확정하는 작업이 필요하다. 알려진 형식은 자동 추출·검증·버전 공개. 새로운 형식, 모순, 생략은 예외 큐로 분리하되 기존 공개 카탈로그는 계속 동작한다.
정형 데이터가 미리 준비된 경우의 무인 배치와 미지의 과학적 결론을 무인 채택하는 것은 다르다.

## 배치와 공개 조건

발견/중복 연구 식별 -> 사용 가능한 원문/보충자료 보존 -> 문서 버전/철회 확인 -> 지원 adapter -> 타입 있는 후보 -> 의미 검증 -> 전체 세션 컴파일 -> 영향 비교 -> 버전 공개.
원문 접근 성공은 과학적 신뢰도와 다른 축이다. 접근 불가 자료는 제외 사유를 기록하며, 공개 XML만 선택해서 생긴 편향을 공개한다.
원문/근거/제품정책 검증 결과를 별도 유지. 통합 '신뢰도90점' 하나로 자동 승인을 결정하지 않는다.
자동 공개는 검증된 적용 규칙을 만족하는 형식/범위에만 허용한다. 원문 해시나 기존 출판 플래그만으로 허용하지 않는다.

## 변형 계약

단위 변경과 장비 반올림은 값 변환, 강도/횟수/빈도/휴식 변경은 훈련 내용 변경으로 구분한다.
운동 대체·요일 압축·세트 감소·보조운동 제거는 원 연구 재현 표시를 제거하고 파생 프로그램으로 버전 관리한다.
각 변형은 허용 전제, 보존하는 항목, 변경량, 근거 규칙, 금지 조합을 가진다. 모든 조합을 허용하지 않는다.
다른 논문에서 좋은 숫자를 하나씩 뽑아 결합했다고 그 조합이 검증된 것은 아니다.
예측 성장률은 제공하지 않는다. 집단의 전후 평균은 개인 성장 곡선이나 인과 설명이 아니다.

## 신규 연구와 갱신

명성/인용수/발표일은 조사 우선순위 신호로만 사용. 대상자 적합성, 설계/비뚤림, 정밀도, 재현·상충 근거를 평가한다.
Crossref/출판사/PubMed 등의 수정·철회 신호 수집을 설계하되 누락 가능성을 명시한다.
새 근거 -> 관련 규칙 식별 -> 충돌/영향 계산 -> 검증된 새 규칙 버전 -> 신규 계획에 반영.
수행 중 계획과 과거 기록은 고정. 철회 등 중대한 경우 신규 시작 차단과 사용자 통지 정책은 별도로 정의한다.

## 먼저 증명할 것

- 개발 참조 3종: 고정 반복/부하 방식, 주차별 변화, 세트별 변화(후자는 클러스터와 분리 가능). 원문 완결성이 확인된 중재만 선택.
- 추출 규칙 작성에 쓰지 않은 별도 평가 세트를 확보한다. 동일 연구의 여러 군은 독립 연구 수로 세지 않는다.
- 참조 자료의 필수 수치/단위/군/주차/휴식/대상자 연결이 전부 맞는지 독립 확인. 치명 오류0은 이 참조 범위의 승인 기준이지 전체 정확도100% 주장이 아니다.
- AI/네트워크 없이 편성·실행·설명까지 재현. 같은 입력/버전이면 같은 결과와 결정 이력.
- 논문 삭제/헤더 뒤집기/단위 오류/부록 누락/상충/철회/서버 장애를 주입했을 때 잘못 공개되지 않는지 확인.
- 전체 세트가 누락 없이 실행·수정·기록 가능하고 재실행 배치가 중복을 만들지 않아야 한다.
- 이후 10~50 등 자료 수 확장은 사용자 상황 커버리지 증가가 있을 때 진행한다. 확보 가능한 완전한 중재 수는 아직 확인되지 않았다.
