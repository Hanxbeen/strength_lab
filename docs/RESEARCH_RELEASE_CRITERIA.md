# 무게무게 — 연구 데이터 실서비스 출시 기준

현재 단계: **review-only**. 자동 공개 루틴 0건, 자동 공개 차트 0건.

## 현재 검증한 것
- PubMed → Europe PMC XML → 원문 문단/표 위치 추출 → 검토 대기열 → 게시 차단 파이프라인.
- `gold_reference.json`은 원본 표에서 별도로 전사한 **소규모 curated reference**. 독립적인 두 명의 사람 검토나 대표성 있는 정확도 측정이 아니다.
- 행 단위 일치율은 일부 선택한 원문 표 셀의 회귀 테스트이며, 운동 프로그램 재현성·군 배정·통계 타당성은 측정하지 않는다.

## 출시에 앞서 반드시 필요한 조건
1. **독립 검토**: 최소 2명 또는 독립적인 검토자와 재확인자가 동일 원문에서 각 군의 주차/세션/운동/보조운동/세트/반복/강도/휴식/증량규칙을 별도 작성하고 불일치 해결. 원문 표·부록·추가자료 누락 검사.
2. **검증 데이터셋**: 양성/음성/급성/리뷰/불완전 원문/복잡한 다중군 사례를 포함한 고정 테스트셋. 정확한 필드별 precision/recall, 치명적 오류율, 검토시간, 누락률 기록. 테스트셋과 개발셋 분리.
3. **실험군별 완전한 실행 매트릭스**: `week → session → exercise → sets/reps/intensity/rest/progression` 필수. 특정 필드가 미상이라면 사용자에게 임의 처방 제공 금지. 연구 원형과 사용자 수정형 별도 버전.
4. **수치 차트**: 원문 행/열/표 위치, 운동종목, 군, 시점, 단위, n, 평균, SD/SE/CI 및 그 유형을 독립 확인. 통계적 비유의성을 동등성으로 표현하지 않기.
5. **게시 절차**: 검토자 서명, 소스 SHA-256, 승인 시간, 변경 불가능한 연구·프로그램 버전, 게시 전 스키마 검증 및 롤백. GitHub Action의 검토 대기 데이터는 서비스 DB에 자동 게시 금지.
6. **운영**: API 재시도/속도 제한, 원문 사용권 및 출처 준수, 실패 배치 재실행, 비용/실패율 모니터링, 원문 수정 감지, 관리자 검수 UI, 개인정보/계정/보안 및 사용자 운동 안전 안내.

현재 `research_release_gate.py`는 서명 및 필드 검증 형식의 **기본 fail-closed 검증기**다. 실제 인증·권한·서명 진위, 원문 해시 대조, 실행 매트릭스 의미 검증 및 서비스 배포 연동은 아직 구현되지 않았다. 검증기가 승인 가능 형식을 수용하는 테스트가 있다고 해서 실제 사람 검토가 끝난 것은 아니다.
